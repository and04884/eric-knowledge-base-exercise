
# Memory & RAM Overview
Random Access Memory (RAM) is a temporary workspace where the computer stores data it needs *right now*. Unlike storage drives, RAM is volatile — meaning its contents disappear when the system powers off.

## Types of Memory
### RAM
Used for active tasks and applications.  
### Cache
Small, ultra-fast memory located inside the CPU.  
### Virtual Memory
A combination of RAM and storage used when physical memory is full.

## Why RAM Matters
More RAM allows a system to run more applications without slowing down. Insufficient RAM often causes freezing, stuttering, or long load times.

### Common RAM Issues
- System crashes during heavy workloads  
- Applications closing unexpectedly  
- Slow performance when multitasking  

## Connections to Other Pages
RAM directly affects how efficiently the [[cpu-basics|CPU]] processes instructions. It also interacts with [[storage-devices|storage]] when virtual memory is used.

> RAM acts as the bridge between the CPU’s speed and the storage system’s capacity.

Understanding RAM helps you optimize performance and troubleshoot memory-related problems.
